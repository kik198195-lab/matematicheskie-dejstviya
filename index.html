🧩 Компоненты действий

слагаемое + слагаемое = сумма
уменьшаемое − вычитаемое = разность

множитель · множитель = произведение
делимое : делитель = частное

+

Сложение

  • сколько всего? вместе?
  • на … больше
  • увеличь на …
  • прибавь, добавили ещё
  • найди сумму
−

Вычитание

  • сколько осталось?
  • на … меньше
  • уменьши на …
  • на сколько больше? меньше?
  • найди разность
·

Умножение

  • в … раз больше
  • увеличь в … раз
  • … раз по …
  • найди произведение
:

Деление

  • в … раз меньше
  • уменьши в … раз
  • во сколько раз больше? меньше?
  • раздели поровну
  • найди частное

🔎 Как найти неизвестное

слагаемое = сумма − другое слагаемое
уменьшаемое = разность + вычитаемое
вычитаемое = уменьшаемое − разность

множитель = произведение : другой множитель
делимое = частное · делитель
делитель = делимое : частное

«на 5 больше» — это +, а «на сколько больше?» — это −
«в 3 раза больше» — это ·, а «во сколько раз больше?» — это :
